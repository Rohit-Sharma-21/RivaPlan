# Sample Data

This folder contains sample datasets for testing **RivaPlan**.

## Study Area
- Ghaghara River
- Rapti River

## Coordinate Reference System
- EPSG:32644 (WGS 84 / UTM Zone 44N)

## Included Datasets

### Ghaghara River
- `ghaghara_lb_1989.gpkg` — Left bank (1989)
- `ghaghara_rb_1989.gpkg` — Right bank (1989)
- `ghaghara_lb_2025.gpkg` — Left bank (2025)
- `ghaghara_rb_2025.gpkg` — Right bank (2025)

### Rapti River
- `rapti_lb_1989.gpkg` — Left bank (1989)
- `rapti_rb_1989.gpkg` — Right bank (1989)
- `rapti_lb_2025.gpkg` — Left bank (2025)
- `rapti_rb_2025.gpkg` — Right bank (2025)

## Purpose

These datasets can be used to test the following RivaPlan tools:

- Bank Lines to Centerline
- River Width
- Sinuosity
- Curvature
- Centerline Migration
- Bankline Migration
