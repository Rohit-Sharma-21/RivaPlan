RivaPlan v2.1.1

Release type: Focused centerline-generation maintenance and documentation update
Release date: 12 November 2026
Status: Experimental; v2.1.1 prepared for submission to the QGIS Plugin Repository

Software name: RivaPlan
QGIS plugin package identifier: Planform_Morphology
Programming language: Python / PyQGIS
Windows development/test environment: QGIS 3.40.13
Minimum QGIS version declared in metadata: 3.28 (not verified as a compatible minimum)

Included Processing tools (7):
1. generate_centerline.py — Bank lines to centerline
2. reverse_line_direction.py — Reverse Line Direction
3. width.py — River Width
4. centerline_shift.py — Centerline shifting
5. shifting_calculation.py — Bankline Shifting
6. sinuosity.py — Line sinuosity
7. curvature.py — Local Curvature

Changes specific to v2.1.1:
- Centerline-generation bank-exclusion buffer distance is now adjustable (default 0.50 m).
- Refined Voronoi clipping/filtering and Dijkstra route tracing within the centerline algorithm.
- Added centerline containment and bank-crossing diagnostic messages.
- Expanded documentation, interface screenshots, and natural/synthetic sample-data descriptions.

Earlier major update, v2.1.0:
- Added the seventh tool (Reverse Line Direction).
- Improved centerline and width geometry handling, configurable processing parameters, downstream-oriented migration calculations, quality-control flags, sinuosity, curvature, and validation.
- Added automated regression testing and GitHub Actions.

Verification:
- Current code: 16/16 standalone regression checks passed on Windows after the v2.1.1 centerline update.
- Adjustable bank-exclusion buffer tested interactively in QGIS.
- The earlier v2.1.0 revision also passed the GitHub Actions Ubuntu workflow. A fresh Ubuntu CI run for v2.1.1 remains to be confirmed after pushing the new source code.
- No code-coverage percentage, maximum vertex capacity, or universal version compatibility is claimed.
