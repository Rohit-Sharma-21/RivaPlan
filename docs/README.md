# RivaPlan Documentation

This directory contains documentation for the **RivaPlan QGIS plugin**.

RivaPlan provides tools for automated river planform morphology analysis within the QGIS Processing framework.

## Documentation

Detailed documentation will be provided for the following tools:

1. [Centreline Generation](centreline.md)
2. [River Width](width.md)
3. [Bankline Shifting](bankline_shifting.md)
4. [Centreline Shifting](centreline_shifting.md)
5. [Sinuosity](sinuosity.md)
6. [Local Curvature](curvature.md)

Additional documentation will include:

- Installation and setup
- Input data requirements
- Example workflows
- Output interpretation
- Sample datasets
- Troubleshooting
